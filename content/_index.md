# 合约交易所核心系统

我们从一个朴素问题开始：**用户发来一笔限价单，系统怎样既快速响应，又保证成交、资产和风险状态最终一致？**

本书不是交易策略教程，也不声称复刻任何交易所内部实现。它把主流中心化交易所公开的合约规则与 API 当作外部行为样本，然后从工程约束推导一套可讨论、可实验的参考架构。

## 读完后你应能

- 从订单状态变化推导订单簿和撮合的必要不变量；
- 设计成交、账本、仓位、保证金和强平之间的责任边界；
- 解释标记价、指数价、资金费率在风险闭环中的作用；
- 设计幂等、事件重放、行情快照/增量恢复和对账流程；
- 根据公开接口观察产品行为，同时区分事实与实现假设。
