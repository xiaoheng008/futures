# 从一张合约，到一套风险闭环

这本书面向有后端开发基础的读者。我们从一个问题开始：**用户提交一笔合约委托，系统怎样把它变成可确认的成交、正确的账户状态，并在风险越界时有序减仓？**

```text
合约单位说不清
  → 订单参数无从校验
  → 订单簿需要公平排序
  → 成交必须只记一次
  → 仓位和挂单共同占用保证金
  → 风险需要可信的标记价格
  → 亏损越界需要强平与缺口处理
  → 服务或连接中断需要重放和重同步
```

每一步都先遇到旧办法的限制，再引出新抽象；章节末尾会把新能力转化成下一道问题。学习路线是按概念因果重建的教学顺序，不是任何交易所的历史或内部架构披露。
