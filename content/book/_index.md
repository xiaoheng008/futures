# 学习约定

版本：**v1.0**。全书 11 章提供递进算例、系统图、配套实验与折叠参考解答。[查看定稿说明](../docs/release/)。

本教程聚焦中心化交易所的数字资产线性永续合约核心链路，以一笔 BTC-USDT 委托和一个账户贯穿规格校验、订单接入、撮合、账本、保证金、强平与故障恢复。交割合约和期权不在本教程范围内。自造数据用于推导，不代表 Binance、Bybit 或 OKX 的现行交易参数。产品规则与公开接口会在对应章节注明范围和来源；无法从公开资料核实的内部设计均标记为教学参考模型。

请按目录树顺序阅读。每章从一个具体问题开始，让现有办法先遇到限制，再引出新概念。关键专业术语首次出现时附英文名或缩写；完整术语按章节收在中英术语表中，API 字段保留原名。章节实验可手算或运行；重建题用来检验你能否从旧问题重新推出新能力。
