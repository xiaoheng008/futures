# 学习约定

本书用一个线性 BTC-USDT 永续账户作为贯穿例子。自造数据用于推导，不代表 Binance、Bybit 或 OKX 的现行交易参数。产品规则与公开接口会在对应章节注明范围和来源；无法从公开资料核实的内部设计均标记为教学参考模型。

请按目录树顺序阅读。每章从一个具体问题开始，让现有办法先遇到限制，再引出新概念。章节实验可手算或运行；重建题用来检验你能否从旧问题重新推出新能力。
