# 实验：订单生命周期与重试

用纸笔或复制下表，模拟 `BUY 0.01 @ 60,000`，假设依次成交 0.004、0.003，再撤销剩余量。

| 步骤 | 输入/事件 | 累计成交 z | 剩余 r | 状态 | 重试是否新建订单？ |
|---|---|---:|---:|---|---|
| 1 | 客户端发送创建请求，响应超时 |  |  |  |  |
| 2 | 服务端接受并分配 orderId |  |  |  |  |
| 3 | 发生第一笔成交 |  |  |  |  |
| 4 | 客户端以同一 clientOrderId 重试 |  |  |  |  |
| 5 | 第二笔成交后撤单确认 |  |  |  |  |

检查 `q = z + r`。讨论：重试换了 clientOrderId 会怎样？撤单响应晚于成交推送到达，客户端怎样避免把旧状态覆盖新状态？
