# 数字资产永续合约交易系统 · v1.0

定稿日期：2026-10-05。副标题：从一笔委托推导撮合、账本与风险处置。

## 本版范围

面向有后端开发基础的读者，围绕中心化交易所线性永续合约的委托、撮合、账本、风险、价格、强平、恢复、推送和容量，完成 11 章因果递进教程。反向合约作为单位对照；真实全仓/组合风险用适用边界解释，不把单仓简化公式冒充通用算法。

每章有问题与尝试、逐步算例、图示、实验、四级掌握检查和下一步问题。所有实验提供提示与参考解答；第 3 章另附 Python 模拟器和自包含 notebook。完整英文名称与 API 字段解释见[中英术语表](/futures/docs/glossary/)。

## 定稿检查范围

- 数值：复算规格、加权均价、平仓盈亏、费用、保证金阈值、资金费、强平缺口与队列数量。
- 边界：区分订单终态与仓位、余额与权益、预留与付款、市场执行与客户结算；明确故障恢复与序号作用域。
- 教学：保留先预测再展开答案的节奏，补全所有实验解答，开放题以不变量评审。
- 引用：复核 Binance、Bybit、OKX 对外规则的相关页面，记录 2026-10-05 访问日期，清楚标注产品/账户范围。[资料与边界](/futures/docs/sources/)。
- 发布：固定 Hugo/OINK 工具链，严格生产构建；检查桌面与移动端页面、公式、图示、内部链接和发布工作流。

验证结果及检查数量在[技术审校记录](/futures/docs/technical-review/)中记录。

## 定稿后的更新

v1.0 是本版教程的完成状态。交易所接口与产品规则继续变化，后续按勘误和版本更新正文、实验与引用。内部流程均为教学参考设计；它们没有被公开 API 证明为某家交易所的部署实现。
